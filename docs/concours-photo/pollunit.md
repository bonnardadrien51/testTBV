# Vote des bénévoles et PollUnit

## Création d'un sondage

Pour chaque photographe :

1. Aller sur PollUnit.
2. Cliquer sur **Concours photo**.
3. Cliquer sur **Créer un nouveau PollUnit**.
4. Ajouter le nom du photographe dans la description.
5. Ajouter les **10 photos**.
6. Vérifier les paramètres.
7. Choisir le thème et les effets.
8. Laisser les autres options par défaut.
9. Cliquer sur **Sauvegarder**.
10. Copier et conserver le lien généré.

## Attention à la taille des photos

Les photos importées dans PollUnit ne doivent pas dépasser **5 Mo par fichier**.

Si nécessaire :

[Compresser les images avec Compress JPEG](https://compressjpeg.com/fr/)

## Organisation du vote

Créer **un sondage par photographe**.

Les liens sont ensuite transmis aux bénévoles, soit directement, soit par l'intermédiaire du responsable bénévoles.

Prévoir environ **7 à 10 jours** de vote.

## À la fin du vote

Pour chaque photographe :

1. consulter les résultats ;
2. identifier les 3 photos ayant obtenu le plus de votes ;
3. récupérer les 3 photos ;
4. créer un dossier pour le photographe ;
5. conserver les informations utiles au classement.
