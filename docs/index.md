# Concours photo – Tout Besançon Vole

Documentation opérationnelle pour organiser le concours photo.

## Principe

Le concours se déroule en deux phases :

1. **Vote des bénévoles** : chaque photographe transmet 10 photos et les bénévoles sélectionnent les 3 meilleures.
2. **Vote du public** : les 3 photos retenues sont publiées sur **Besançon, J’aime ma Ville** et le public vote.
